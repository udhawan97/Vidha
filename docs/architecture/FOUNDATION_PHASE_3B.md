# Phase 3B executable foundation

**Status:** Phase 3B is in progress. The six intermediate foundation slices and closure slices 1–2 now have disposable, synthetic executable gates; every exact commit still requires those gates to pass. This is not a completed phase, hosted deployment, production environment, real-account system, Standard Mode, Sealed Mode, Release authority, or v1 release.

Phase 3B moves the accepted Phase 3 operational decisions into production-shaped adapters while preserving the hard stop at Concern. The runnable browser prototype remains in-memory and synthetic; the new server adapters are exercised only by local unit contracts and mandatory disposable CI gates.

## Verification boundary

`pnpm check` is the local deterministic gate. It includes format, lint, type, unit/contract, build, and documentation checks. The mandatory GitHub workflow adds:

- a fresh PostgreSQL 18 service and cross-process persistence/contention/restore-safe tests;
- PostgreSQL migration/claim backend termination, rollback/restart, pool exhaustion, and the fixed synthetic capacity profile;
- the digest-pinned migrator/API/worker/PostgreSQL Compose topology, including worker partition/recovery and tmpfs-root destruction;
- the authenticated logical-backup, atomic key-rotation, external inventory, isolated restore-safe inspection, and explicit-promotion rehearsal;
- source-hash-verified file 5.48, Pandoc 3.10.2, and digest-pinned ClamAV 1.5.4 executable tests; and
- desktop and mobile WebKit acceptance for the existing synthetic PWA.

Passing that workflow verifies only the disposable fixtures at the tested commit. It does not pass sections 1–11 of the v1 release gates.
