# Use Standard Mode first and make Sealed Mode optional

Every Envelope has one Protection Mode covering its Editable Documents and Attachments, so file format never creates an unprotected exception. Standard Mode uses per-item encryption with service-managed keys so Owners can recover access and Recipients are not forced through advance key setup. Operator decryption remains technically possible only through a restricted, audited break-glass process. The accepted Sealed Mode target is an optional operator-unreadable path that trades recoverability and server-assisted features for stronger confidentiality; it remains absent or unarmable unless its protocol, recovery contract, independent review, and test vectors pass. The ADR does not establish a current zero-knowledge claim.
