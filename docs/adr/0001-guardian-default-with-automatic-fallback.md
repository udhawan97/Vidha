# Use bounded Guardian Attestations by default with an Automatic Fallback

Silence alone cannot distinguish death from lost access, hospitalization, travel, or provider failure, so bounded Guardian Attestations are the default Release Policy for every Envelope. The exact attestation never asks a Guardian to declare death. An Owner may deliberately enable an Automatic Fallback for an individual Envelope, but only with an extended minimum delay and explicit risk acknowledgement. Every Release Policy still requires a fresh final Veto Window. It starts only after at least one verified Owner channel accepts the final notice; if all channels fail before Release, including through later negative delivery evidence, the Envelope enters Delivery Hold and must later start a new full window. Outage catch-up cannot compress these stages. Vidha never interprets inactivity or an attestation as proof of death; per-Envelope policies preserve meaningful Owner control without weakening more sensitive material.
