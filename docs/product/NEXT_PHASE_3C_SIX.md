# Phase 3C canonical documents and portability

**Status:** Six bounded source slices are implemented locally; exact-commit CI acceptance remains required. This phase is a synthetic browser and module milestone, not durable content storage, production import support, deployment, or release authority.

Phase 3C returns from infrastructure rehearsal to one Owner-facing release-gate seam: understanding what becomes an Editable Document, reviewing conversion consequences before acceptance, preserving the source, and taking a portable copy. It does not accept personal data or broaden the contingency state machine beyond Concern.

## Gate after Phase 3C

Exact-commit local and CI checks must pass, including the existing Phase 3B disposable PostgreSQL, WebAuthn, backup, scheduler, and rootless-import rehearsals. Passing proves only the versioned synthetic document interface and browser review flow at that commit. It does not authorize real identities or content, durable storage, Standard Mode, Sealed Mode, providers, Guardian Attestations, final notice, Veto Window, Delivery Hold, Automatic Fallback, Release, deployment, a tag, or a GitHub release. Every checkbox in sections 1–11 of `docs/release/V1_RELEASE_GATES.md` remains evidence-gated.
