# Support

Vidha is pre-alpha. There is no hosted service, installation, or supported release to troubleshoot yet.

- Use GitHub Discussions, or the dedicated **Product or documentation question** issue form, for public questions based only on synthetic examples.
- Use the bug template only for behavior reproducible with synthetic data.
- Use private vulnerability reporting for security issues only when GitHub shows the verified report form; otherwise disclose no details and use only the **Request private security contact** issue form.
- Do not upload real plans, Documents, Attachments, contact information, recovery material, or provider credentials.

Vidha is not an emergency service. If someone may be in immediate danger, contact the appropriate local emergency service or a trusted person rather than relying on this project.
